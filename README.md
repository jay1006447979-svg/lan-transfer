# LAN Transfer 2.0

**局域网文件 / 文字传输工具。** 手机、平板、其它电脑打开浏览器就能用，**对方不用装任何 App**。

Windows 一键运行，纯 Python 标准库实现，无需 pip 安装任何依赖。

```
┌─────────────┐        同一个 Wi-Fi        ┌──────────────┐
│  电脑 (本机) │  ◄──────────────────►  │  手机 / 平板   │
│  运行 EXE    │      浏览器打开网址       │  浏览器打开    │
└─────────────┘                            └──────────────┘
```

## 特性

| | |
|---|---|
| 📤 **大文件传输** | 自动分块（16MB）+ **断点续传**，断网 / 锁屏 / 关网页都能接着传 |
| 🧠 **低内存占用** | 上传落盘、下载发送、文件夹打包 ZIP 全部**流式**处理，内存恒定 |
| 📁 **文件夹传输** | 递归上传保留目录结构；文件夹下载流式打包成标准 zip |
| 📝 **文字传输** | 收发文字、持久化历史、一键复制（含安卓 HTTP 降级）、读取剪贴板 |
| ⚡ **实时进度** | 当前速度 / 平均速度 / 剩余时间 / 可取消 / 可重试 |
| 🎨 **好用界面** | 浅色深色自动适配、移动端友好、拖拽上传、中文文件名不乱码 |
| 🔒 **安全可控** | 路径穿越防护、`--read-only` 只读、`--token` 访问令牌 |

## 快速开始

### 方式一：下载 EXE（推荐）

到 [**Releases**](https://github.com/jay1006447979-svg/lan-transfer/releases/latest) 页面
下载 `LAN-Transfer.exe`，双击运行：

1. 窗口里会先显示**使用说明**
2. 按回车键启动服务
3. 把提示的网址（形如 `http://192.168.1.20:9876`）输入到手机浏览器

共享目录默认是 **EXE 同目录下的 `shared_files`** —— EXE 拷到哪，数据就跟到哪。

> 首次运行可能被 Windows Defender / 360 误报（PyInstaller 打包程序常见现象），
> 选择「仍要运行 / 允许」即可。

### 方式二：源码运行

```bash
git clone https://github.com/jay1006447979-svg/lan-transfer.git
cd lan-transfer
python server.py
```

需要 Python 3.8+，无第三方依赖。

## 使用说明

### 三个页签

- **文字** —— 发文字、读剪贴板、获取最新内容
- **文件** —— 上传 / 下载 / 删除文件与文件夹，查看共享文件列表
- **记录** —— 文字历史，可搜索、复制、删除

### 多设备互传

不限于"电脑 ↔ 手机"。同一个局域网内**任何**设备打开网址都能互相看到共享文件，
多方互传也行。

### 断点续传

上传大文件时如果中断（断网、锁屏、关页面、关掉浏览器），**不用从头再来**：
重新选择同一个文件，服务端会识别出已上传的分块，从断点继续。

上传进度会显示：当前速度、平均速度、剩余时间、百分比。

### 手机上选不了文件夹？

这是**手机浏览器的限制**，不是工具的问题。

选择文件夹依赖 HTML 的 `webkitdirectory` 属性，它只在桌面浏览器有效：

| 平台 | 选择文件夹 |
|---|---|
| Chrome / Edge / Firefox（电脑） | ✅ 支持 |
| 安卓 Chrome / 手机浏览器 | ❌ 属性被忽略 |
| iOS Safari / Chrome | ❌ 同上 |

**手机端的解决办法**：先用文件管理器把文件夹压缩成 zip 再上传，或改用「多选文件」。

## 命令行参数

```
-p, --port        端口（默认 9876，被占用会自动 +1 尝试）
-d, --dir         共享目录（默认 ./shared_files）
--bind            监听地址（默认 0.0.0.0；用 127.0.0.1 则只有本机可访问）
--token           访问令牌；设置后前端会自动带在请求里
--read-only       只读模式，禁止上传 / 删除
--no-overwrite    同名文件自动重命名，不覆盖
--open            启动后自动打开本机页面
-h, --help        查看全部参数
```

示例：

```bash
python server.py -p 8080 -d D:\share          # 换端口和目录
python server.py --read-only                  # 只让别人下载，不能传/删
python server.py --token mypass123            # 加访问令牌
python server.py --bind 127.0.0.1 --open      # 只本机用
```

## 项目结构

```
lan_transfer/
├── server.py            # 服务实现（HTTP 服务 + 内嵌前端页面）
├── launcher.py          # EXE 入口：打印使用说明、设置默认共享目录
├── LAN_Transfer.spec    # PyInstaller 打包配置
├── 启动.bat             # 源码方式的一键启动脚本
└── README.md
```

内部数据（上传会话、分块索引、文字历史）存放在共享目录下的 `.lan_transfer/`：

- `index.db` — SQLite 数据库
- `chunks/` — 上传中分块暂存（合并后自动清理）

该目录不会出现在网页的文件列表里，打包 ZIP 时也会跳过。
超过 7 天未续传的会话会在下次启动时自动清理。

## 实现要点

几个值得一提的技术细节：

- **分块按内容哈希寻址**：每个分块以自身 SHA-1 命名存放，重复上传天然幂等，
  从根上避免「分块丢失 / 合并缺块」这类问题。
- **上传会话持久化**：会话状态存 SQLite，`/api/upload/init` 返回服务端已有的分块列表，
  前端据此只补缺失的分块 —— 这就是断点续传的实现方式。
- **手写流式 ZIP**：文件夹打包用 `ZIP_STORED` + 预置 CRC，本机手写 ZIP 结构，
  边读边发（`Transfer-Encoding: chunked`），内存占用与文件夹大小无关。
- **不依赖安全上下文 API**：前端不使用 `crypto.subtle` 等仅 HTTPS 可用的接口，
  因此在手机用 `http://192.168.x.x` 访问时功能完整可用。
- **路径安全**：用 `realpath` + 公共前缀校验（而非 `startswith`），
  拒绝盘符、`..`、以及内部数据目录。

## 注意事项

- 这是**局域网明文 HTTP** 工具，适合家庭 / 办公内网，**请不要在公网直接暴露**。
- 能访问该网址的人都能**查看 / 下载 / 删除**共享目录里的文件。
  敏感场景请配合 `--read-only` 或 `--token` 使用。
